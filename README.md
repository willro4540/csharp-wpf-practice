## WpfApp4 — 윈도우 계산기 UI 복제 (2026-09-07~)

교수님 블로그(`basiclike.tistory.com/404`) 실습을 따라, 실제 Windows 계산기 외형을
그대로 복제하는 새 프로젝트입니다. `WpfApp2`(사칙연산 로직 위주, 이미 완성)와는
별개로 "정확한 UI 레이아웃"에 초점을 맞춘 실습이라 프로젝트를 분리했습니다.

- 01단계: 창 크기 322×534, `ResizeMode="NoResize"`로 고정
- 02단계: `Grid` 4열 x 7행(결과창 1행 + 버튼 6행) 구성
- 03단계: 결과 표시 `Label`(우측 정렬, `FontSize=46`) + 버튼 24개 배치
- 04단계: `⌦`(U+2326), `÷`, `×`, `−` 등 특수 기호를 유니코드로 직접 지정
- 05단계: `WpfMath` NuGet 패키지(`FormulaControl`)로 `x²`, `√x`를 실제 수식
  형태로 렌더링 (일반 텍스트 대신)

**검증 방법**: 실행 후 UI Automation으로 컨트롤 트리를 순회해 24개 버튼 + 1개
Label이 전부 올바른 이름으로 생성됐는지 구조적으로 확인함(화면 캡처는 DPI
스케일링/포그라운드 전환 문제로 신뢰도가 낮아 보조 수단으로만 사용). 연산자
클릭 로직(`+`, `=` 등 실제 계산)은 이 단계에서는 아직 연결하지 않음 — 404번
글 자체가 UI 레이아웃까지만 다루고 있어서, 로직은 다음 실습(후속 글) 범위로
남겨둠.
